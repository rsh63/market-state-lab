### DRL Improvements for the MATLAB System

1. Add release phase, payroll/wage/revision surprises, NQ–ES strength, yield response, VX slope, quote age, and auction state; expose each feature only after publication.
2. Enforce drawdown, concentration, turnover, liquidity, and daily-loss constraints outside the reward; penalize downside risk, impossible fills, and implementation shortfall inside it.
3. Randomize release gaps, depth loss, spreads, partial fills, latency, fees, and nonlinear impact; test independent risk monitors and agent shutdown.
4. Use purged, embargoed walk-forward folds with frozen baselines, multiple seeds, regime scorecards, and untouched payroll/expiry blocks.

### Model hygiene

Control leakage, survivorship and look-ahead bias, publication timestamps, corporate actions, stale options quotes, and multiple testing. Preserve macro vintages and historical ETF membership. Calibrate out of sample, retain rejected trials, and monitor feature, probability, policy, transaction-cost, and regime drift.

### MATLAB optimization

- Align market, macro, session, and auction data with `timetable`, `retime`, and `synchronize`; preserve first-known timestamps.
- Vectorize rolling features, preallocate buffers, and profile environment steps before parallelizing.
- Run parallel `bayesopt` across independent purged folds with reproducible random streams and multiple seeds.
- Reserve GPUs for sufficiently large neural-network batches; separate environment, cost, constraint, validation, and agent modules.
