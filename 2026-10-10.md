*Credit: original Market State Lab category illustration; not an event photograph.*

It says identified cases caused minimal real-world impact and that it expanded internet isolation across internal evaluations. [Source: Anthropic, October 9](https://www.anthropic.com/research/investigating-unintended-model-actions)

## 2. Limit-order-book research challenges hard regime labels

![Abstract quantitative models and limit-order-book illustration](https://raw.githubusercontent.com/rsh63/market-state-lab/main/story-2-quant.png)

*Credit: original Market State Lab category illustration; not an event photograph.*

**Fact:** An October 6 preprint revision analyzes 987 EURO STOXX 50 futures trading days from 2022–2025. It finds largely continuous market-state geometry; coarse regime tiers generalize more reliably than fine bins in expanding-year evaluation. [Source: Thawait, arXiv v2, October 6](https://arxiv.org/abs/2610.05740)

**Inference:** Continuous stress features may retain information that discrete regime labels discard.

**Uncertainty:** The preprint is not peer reviewed. One futures market and geometric prediction do not establish tradable SPY/QQQ alpha.

**Why it matters:** Compare continuous stress inputs against hard regime bins using purged walk-forward tests and realistic execution costs.

### DRL Improvements for the MATLAB System

1. Compare continuous liquidity-stress inputs with discrete regime labels; add session, weekend/holiday, quote-age and event-countdown states.
2. Enforce drawdown, concentration, turnover, liquidity and daily-loss constraints outside the reward. Penalize implementation shortfall and downside risk; retain a valid no-trade action.
3. Randomize gaps, depth withdrawal, spread widening, latency, partial fills and nonlinear impact. Test agent tools against offline fixtures with external actions disabled.
4. Use purged, embargoed walk-forward evaluation, frozen baselines, nested tuning, multiple seeds and untouched holiday/event blocks; retain all trials.

### Model hygiene

Control leakage, survivorship and look-ahead bias; preserve first-known timestamps and corporate actions. Filter stale options quotes, count multiple tests, calibrate out of sample, and monitor feature, probability, execution-cost and policy drift.

### MATLAB optimization

- Align session, macro and market data with `timetable`, `retime` and `synchronize`, preserving release timestamps.
- Vectorize rolling features, preallocate episode buffers and profile environment steps before parallelizing.
- Run parallel `bayesopt` across independent purged folds with reproducible random streams.
- Use GPUs for sufficiently large neural-network batches; keep environment, execution-cost, constraint and agent modules separate.

Testing this separates the value of regime representation from session effects and executable trading performance.
